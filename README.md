# AI Registry — Amazon Web Services

Vendor repository for the [AI Registry](https://github.com/eclipsefdn-ai-registry/ai-registry-core), maintained by [Amazon Web Services](https://aws.amazon.com). Contains approvals for AI artifacts (MCP servers and Agent Skills) approved by AWS.

## Documentation

See the [Vendor Guide](https://github.com/eclipsefdn-ai-registry/ai-registry-core#vendor-guide) in the central repository for how vendor repos work, how to add approvals, and how validation runs.
